# AgroMak E-Commerce Platform

A modern fullstack agricultural e-commerce platform that connects buyers and sellers in a seamless online marketplace experience.

Built with a scalable architecture using React, Node.js, Express, PostgreSQL, and Prisma ORM.

---

# Project Overview

MyAgro is a full-featured e-commerce application designed to provide users with a secure and user-friendly shopping experience for agricultural and farm-related products.

The platform supports:

- Buyer authentication and shopping experience
- Seller product management
- Cart and wishlist systems
- Checkout and payment processing
- Address management
- Order management
- Cash on Delivery and Paystack payments
- Inventory and stock management
- Responsive modern UI/UX

This project demonstrates strong frontend and backend engineering practices, API integration, database design, authentication flow, and scalable application architecture.
